# EchoMind
EchoMind is a 2D puzzle game where the player does not control the present,
but instead records actions that are replayed in the future as autonomous agents.

The goal is to solve puzzles by synchronizing past actions, environment changes,
and enemy behaviors.

---

## 🎮 Gameplay Concept

- The player records a sequence of actions (move, wait, interact)
- These actions are replayed in a loop by an "Echo"
- The player can modify the environment while echoes are replaying
- Multiple echoes can exist at the same time

---

## 🧠 Core Mechanics

- Action recording & replay
- Autonomous agents (Echoes)
- Time-based puzzles
- Grid-based movement
- Finite State Machines (FSM)

---

## 🛠️ Tech Stack

- Language: C++
- Graphics: SFML
- Architecture: Agent-based design
- Paradigm: Object-Oriented Programming
